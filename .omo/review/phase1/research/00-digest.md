# Research digest: Orchestrion PR #858 lessons applied to dd-iast-go

Inputs: `research/runtime.md` (runtime registry), `research/injector.md` (join points), `research/shadow.md` (patched Go compiler/runtime), and `research/cases.md` (e2e catalogue). These were compared with dd-iast-go HEAD 2e23b46: README, `internal/taint/store/*`, `iast/propagation/operators.go`, `internal/taint/propagation/{propagation,conversion,string_exact,string_coarse}.go`, `internal/taint/request/{scope,owner,reader}.go`, and `iast/net/http/orchestrion.yml`.

Check references: `R#` = runtime.md CHECK, `I#` = injector.md CHECK, `S#` = shadow.md scenario. A check marked **static-OK** was confirmed by res-digest from code alone and nothing was run. Downstream nodes should still try to reproduce the **open** checks, the P1 ones first.

## 1. The three designs compared

| Axis | Research runtime registry (`runtime/taint`) | Research go-shadow (patched Go 1.26.1) | dd-iast-go (HEAD 2e23b46) |
|---|---|---|---|
| Identity | Absolute address intervals per kind. Lookup is by interval overlap, so every sub-view resolves without being registered. | A per-byte shadow bit on backing memory plus an SSA label per string value. Taint survives any header copy. | Exact `(pointer, length, kind)` key (`store.go:41-61`), resolved to an owner-local root window (`value.go:35-49`, `lookup.go:107-198`). Views are visible only if a wrapper called `Derive`/`putWindow`. |
| Fresh storage at sources | `isolatedString` copies into `len+1` bytes, which defeats `staticuint64s` and `""+s` aliasing. | Not needed, because the shadow sits on bytes. | Sources are cloned (`root.go:40,80,120,162`). 1-byte roots are refused (`root.go:27-30,67-69`). Alias results (`""+s`, unchanged case conversion) are routed to `Derive` and never adopted (`string_exact.go:25-40`, `string_coarse.go:42-45`, `propagation.go:163-165`). |
| Lifetime / address reuse | Every tainted array is pinned for the process, so addresses are never reused. The cost is a leak. | The shadow is cleared on GC sweep and on exact-address heap reuse. | Anchors are strong until the owner finishes. Finish first sets `stateFinishing` (CAS), then takes `lifecycleMu.Lock`, then clears the anchors (`owner.go:162-201`). Lookups need `stateActive` under the lifecycle RLock (`lookup.go:148-155`). Stale slots are rejected by `ownerGen`/`rootGen` (`value.go:231-243`). |
| Request boundary | A process-global `StartRequest` keeps one retired generation, so concurrent requests evict each other. | None. | One owner per sampled request, at most 64 slots (`limits.go:9`). `Entry.Handle` revalidates index, gen, state, and ID before any publish (`lookup.go:35-44`). `beginWrite` rechecks liveness (`owner.go:131-149`). |
| Bounds | String, byte, and rune ranges and owners are unbounded. Builder and reader tables hold 65,536 each. | Arena shadow allocated unconditionally. No record cap. | Fixed arrays: 256 shards x 128 slots, 16,384 process values, 8 MiB process and 2 MiB request root charge, 512 roots per owner, 256 values per root, 64 ranges (10 inline), 8 writers per owner (`limits.go`). |
| Saturation | Latches a process-wide `historyDiscarded`/`stateSaturated`, then reports `unknown` on every clean sink. | Not proven. | Drop plus a per-owner counter (`store.go:126-136`). No process-wide latch found (grep for sticky `atomic.Bool`: only per-owner `writerDirty`, `store.go:108`). |
| Concurrency | One blocking RWMutex per generation. Read-modify-write is not atomic. | Runtime-internal. | TryLock/TryRLock everywhere. Contention is a safe miss (`lookup.go:87-89,114-116`). Byte mutation invalidates first with a CAS (`mutation.go:79-99`). Writer contention poisons state through `writerDirty` (`writer.go:127-128,241-258`). |
| Cheap gate | None. Every lookup scans all intervals and allocates. | Implicit (compiler). | `operatorbridge.HasValues()` and `ActiveStore()`, then `MayContain` over a fixed 64-probe window, then `Lookup` in a `//go:noinline` slow path (`operators.go:23-26`, `propagation.go:141-173`). |
| Coverage | Operators, builtins (`append`/`copy`/`clear`), scalars, maps/channels, method values, Buffer read family. Views are free. | Nearly universal inside the patched runtime. Indirect calls and control flow (coarse) are covered too. | Direct calls in the root module, `+` chains of 2-16 operands, slicing, alloc-preserving `[]byte`->`string`, strings/bytes/fmt/url/strconv, writers, and JSON decode (README). No `append`/`copy`/index writes, scalars, method values, regexp, or dependency reslices. |
| Deployability / cost | Stock toolchain. No benchmark. | Forked toolchain, darwin/arm64 only. No benchmark (one data point: 0.66 s and about 18 MB for 65,536 values). | Stock toolchain via pinned Orchestrion `23afa71d6dcb`. Research-only join points (`value-operation`, `insert-statements-after`) are **not** available there (I1). |

The main trade-off is this: dd-iast-go gives up the research's free alias resolution (exact keys) in exchange for hard bounds, no pinning, and request isolation. Its correctness therefore depends on two things. First, every window-producing wrapper must derive correctly. Second, every in-place byte mutation must invalidate. The research reproduced failures in exactly these two places.

## 2. Consolidated CHECKS by dd-iast-go component

### 2.1 Store (`internal/taint/store`)
1. **Invalidate before releasing the anchor** (R3, S28). static-OK: Finish CASes to `stateFinishing` before `lifecycleMu.Lock` and clears anchors only under that lock (`owner.go:162-192`). `Lookup` requires `stateActive` under RLock. Within a live owner, anchors are dropped only by `rollbackRoot`/Finish, and `PublishBytesMutation` requires the same base and span (`mutation.go:51`), so the allocation stays alive. Open: a GC plus same-address reallocation reproducer across two owners (S28).
2. **Owner-slot ABA** (R4). static-OK: `ownerGen` is a `uint64` bumped on every Acquire (`owner.go:53`). `Handle` checks gen, state, and ID. Every mutator goes through `beginWrite`. Open: check that every *non-store* publish path (bindings, sqlbridge, scopebridge) also goes through `Handle`/`beginWrite`.
3. **Root-generation restart after rollback.** `rollbackRoot` resets `root.generation` to 0 and frees the ID (`root.go:391-393`), so the next `publishRoot` on that ID restarts at gen 1 (`root.go:330-333`). This is safe today only because rollback runs before any window for that root generation exists: `putWindow` failed and the `RootRef` was never returned. Keep this invariant in mind for any new caller of `rollbackRoot` (Info).
4. **Exact window span** (R11). static-OK: strings use span `len`, bytes use span `cap` (`root.go:51,132,236,247`). `charge` uses `sizeClass` but never widens the span.
5. **Hard footprint** (R9). Tables are fixed arrays (`store.go:113-181`). Open: adopted byte roots are charged by `sizeClass(cap)`, but the README admits that writer anchors can retain more than they charge. Measure the worst case of retained versus charged.
6. **Saturation direction** (R7, S30). static-OK statically: there is no process-wide latch, and every bound increments a drop counter and returns false. Open: 65,536 tainted values in one request, then assert bounded `ProcessCharged` and no report on clean sinks.
7. **Failed clears** (R8). static-OK for byte mutation (claim first, `mutation.go:30,88`) and for writers (`writerDirty` on TryLock failure). Open: JSON, decoder, and binding invalidation paths.
8. **Same-value concurrency** (R14, S27). Partly covered: `race_test.go:16-86` shares one managed value across Derive, Lookup, Finish, and mutation. Missing: Finish, then **re-Acquire of the same slot** while stale goroutines still publish.

### 2.2 Ranges / propagation (`iast/propagation`, `internal/taint/propagation`, `internal/taint/ranges`)
9. **Runtime-shared addresses** (R1, research pitfall 2). static-OK for concat (`JoinString` alias -> `StringWindow`), copy, and case conversion. `BytesToString` refuses `len<2`, and its result is a heap `string(value)` that escapes (`operators.go:198-204`). Open: audit every remaining `AdoptString`/`AdoptBytes` result caller (`bytes_exact.go:96,179,307,410`, `propagation.go:316,418,475,593,695`, `json.go:60,91,159`, `writer.go:235`) against stdlib fast paths that return the input or a subslice unchanged (`Repeat(s,1)`, `Replace` n==0, `Map`/`ToValidUTF8` unchanged, `bytes.Join` of one element).
10. **Interior views** (R2, S32). By design, an exact-key miss makes a view clean unless a wrapper derived it. Open: every README "window" API (Cut*, Split*, Fields*, Trim*, Lines, sequence variants) derives **each** output, including the `maxWindows=32` cap (`propagation.go:239-240`).
11. **Conservative transforms keep sources** (R12, S31). Coarse paths call `ranges.Coarse` per owner entry (`string_coarse.go:64`). Open: two sources in one owner through `fmt` and `url` stay distinct source IDs and are capped deterministically by `DD_IAST_MAX_RANGE_COUNT`.
12. **Stale ranges on mutable bytes** (R5, R6, S11, S21; research-reproduced). This is P1. Byte roots span `cap`. Windows share the root. `append`/`copy`/index writes are not hooked. `ReadAllBytes` adopts the application's own `io.ReadAll` slice (`reader.go:67-88,116,119`). Port `evidence/res-runtime/zz_review_stale_test.go` to (a) `bytes.Buffer` hooks (`Read` on an empty buffer does an internal `Reset`, then a shorter clean write, then `ReadFrom`) and (b) an in-place `copy(window, clean)` before a sink. The README documents (b) as a trade-off. Measure how often it becomes a false positive on a supported path.

### 2.3 Hooks / `orchestrion.yml`
13. **Pinned join-point contract** (I1, I6). Only `string-concat`, `slice-expression`, and `type-conversion` exist at `23afa71d6dcb`. Keep the exclusions of `iast/propagation`, `taint`, and `internal/**` consistent across all operator aspects (`orchestrion.yml:309-314,330-335`).
14. **Concat** (I2, I3, S8, S18). Only the maximal chain of 2-16 operands is wrapped once. 17+ operands and `+=` must add no false ranges. Named types and `T ~string` return the original type, and each operand is evaluated exactly once.
15. **Conversion** (I4, S10). Only assignment, declaration, and return contexts are wrapped. The wrapper must keep `{{ .AST.Fun }}`. Compiler-optimized contexts stay unwrapped (documented).
16. **Slicing** (I5, S9). Omitted bounds, three-index form, non-`int` bounds, side-effecting bounds, out-of-range **panic identity and order**, and exact len, cap, and window.
17. **Do not import research advice** (I8). Scalars, method values, `insert-statements-after`, and `replace-statement` need a runtime contract that dd-iast-go lacks.

### 2.4 Request lifecycle (`internal/taint/request`, `iast/net/http`)
18. **Finish on every exit** (R17). static-OK: `defer iasthttpbridge.Finish` sits in `serverHandler.ServeHTTP` (`iast/net/http/orchestrion.yml:29-33`), so it runs on panic and on return after a hijack. Late goroutines are dropped by `beginWrite`'s `alive()` check. Open: long-lived handlers keep a permit (see F1 in `res-digest.md`).
19. **No cross-request bleed** (S6, S29). A global written in request A and read in request B must yield no report. So must a goroutine or channel that outlives its request. Statically ensured by `ownerGen` staleness. Needs an e2e reproducer.
20. **Owner/permit coupling.** The analysis permit bitmask (`request/owner.go:65-80`) and store owners (64) must release together. `Analysis.Finish` does both (`owner.go:259-273`). Check the `Acquire` failure paths return the bit (`owner.go:84-92`: yes).

### 2.5 Sinks / reporting
21. **Redaction on every exit** (R15, S37). `DD_IAST_REDACTION_ENABLED=false` is the only documented bypass (`redaction/source.go:48,59,80`). Open: check that no debug, telemetry, or drop-log path emits a raw value.
22. **Method-value sinks** (S5). Exec reports at `os.StartProcess`, so it is covered. SQL through `q := db.QueryContext` is undocumented. Verify it and document the result.
23. **Non-vacuous tests** (shadow process lessons 1-4; res-shadow-F1). Every positive case needs a byte-identical clean control and a disabled control, and must assert exact value, ranges, and source IDs. The woven CI lane must fail rather than skip.

### 2.6 Perf
24. **Cheap gate first** (R10, S35). static-OK: operators check `HasValues()` before calling into internal code, and internal code checks `ActiveStore()` then `MayContain` before `Lookup`/allocation. Open: `MayContain` returns true for *stale* slots until they are lazily reclaimed (`lookup.go:97`), so churn can force slow-path `Lookup`s. Measure `Stats().AverageProbe` and slow-path hit rate after many finished owners.
25. **Contention = silent false negative.** Every TryLock miss drops taint (`drops.contention`). Under concurrent requests on shared shards this is by design, but measure the rate. A high rate would be a rule-4 concern.

## 3. Research findings that suggest dd-iast-go risks (prioritised)

1. **P1: Stale taint on reused mutable bytes** (research reproduced it: `res-runtime/stale_capacity.out.txt`). dd-iast-go has the same precondition: byte roots span `cap`, and in-place writes are not observed. It also adopts application-owned `io.ReadAll` slices. Impact is limited to the owner's lifetime, with no cross-request bleed, but inside that lifetime it can produce false positives on supported sinks. The README documents it as a trade-off, and a reviewer may challenge it at Medium+ if it can be reproduced on a supported path. See check 12.
2. **P1: Buffer paths that are unhooked internally.** `bytes.Buffer.Read` on an empty buffer calls `Reset()` internally, and `grow` slides data. The README says native Buffer hooks invalidate on indirect mutation. Verify this with the research sequence against `iast/propagation/writer.go`.
3. **P2: Exact-key coverage delta** (res-shadow-F2, Info). Any alias created outside root-module wrapped calls is clean: regexp, dependency reslices, method values. This is documented. Report it as coverage, not as a bug.
4. **P2: Same-allocation double roots.** When an already-tracked key is adopted again (the `AddDuplicate` path `reader.go:106-117` if `data` is the same slice, or `writer.go:235`), `putWindow` repoints the slot to the new root (`value.go:172-187`), and both roots charge the same allocation. This is bounded, but it wastes the request budget and makes drops earlier. Open question.
5. **P2: Saturation latch.** None was found. dd-iast-go already avoids research F3 (a process-wide `unknown` flood). Keep this as a regression check.
6. **P3: Toolchain/weaving silent pass** (res-shadow-F1, Low). Add a woven-lane guard.

Coverage scenarios for e2e nodes: shadow.md S1-S37, with S6, S11, S19-S22, S28-S30, and S32 most likely to break rule 4. `cases.md` gives expected values and ranges to port. Use byte-identical clean literals as controls.
